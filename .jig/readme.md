# README Profile

> Basis: user-approved bilingual README structure, 2026-09-28

## Languages

Canonical: `README.md` (English). Mirror: `README.ko.md` (Korean). Update both in the same task when public usage changes. Skill instructions and technical references remain in English.

## Sections

Title and link row, Introduction, Installation, Usage, Skills, Documentation, License.

## Detail Docs

Host-specific installation, updates, and state locations belong in `docs/installation.md`. Workflow and implementation detail belong in `docs/workflow.md`. `docs/README.md` is the documentation home. Evaluation scenarios stay in `TESTING.md`. Link future design and roadmap records from the documentation home rather than the README.

## Conventions

Keep both READMEs concise and equivalent in meaning. Show a usable quick start and link to installation details. Keep identifier table descriptions to one short clause. Put contributor-only commands in detail docs or a collapsed block. Describe only implemented capabilities and distinguish retired Suno models from models available for new generation.
