# v0.3.0 scope

This release combines the compatibility/correctness and expanded-workflow milestones into one package.

| Area | Shipped change |
|---|---|
| Current models | v6, v6-wild, and v6-mini selection and access guidance |
| Historical models | Complete retired-model handoffs, separated from current generation |
| Output | Lyrics, Prompt, Styles, Exclude, and the complete conditional settings ledger |
| Creation | Custom and Simple requests, including wordless and voice-free tracks |
| Editing | Lyric/section edits, extension, cover/remix, multi-source and sampled-input handoffs |
| Account state | Voice, Style Persona, Custom Model, Audio Influence, and Personalize recording |
| Correctness | Translation separation, percent sliders, explicit-language priority, evidence-based diagnosis |
| History | Full JSON snapshots, instrumental sections, independent outcome logs, exact restoration |
| Packaging | One generated plugin bundle with Codex, Claude Code, and Antigravity manifests |
| Documentation | English/Korean README and separate installation, migration, evaluation guides |

The package prepares text and records. It does not add a Suno audio API, automatic paid generation, or browser automation. Actual UI availability and generated audio still need user-side verification.
